# פרויקט השו"ת (בר אילן) לאוצריא

תוסף לאוצריא שמחבר אותה לתוכנת **פרויקט השו"ת של אוניברסיטת בר אילן** המותקנת במחשב. התוסף מאפשר:
- לחפש את ספרי בר אילן לפי שם או מחבר;
- לראות לכל ספר מחבר, מקום ושנת הדפסה;
- לפתוח את הספר בבר אילן בלחיצה.

> **בפיתוח.** ראו את [תוכנית העבודה](https://github.com/Otzaria/otzaria/issues/1593).

## איך זה עובד

- **התוסף:** HTML/JS שרץ בתוך אוצריא.
- **השירות המקומי:** `helper/`, תוכנה קטנה שרצה ברקע.
- **התקשורת:** התוסף פונה לשירות ב-`127.0.0.1`, לפי [הפרוטוקול](docs/PROTOCOL.md).
- **מה השירות עושה:** קורא את קטלוג הספרים מבר אילן ופותח בו ספרים.

אותו מבנה כמו תוסף היברובוקס.

## מה התוסף לא עושה

- **לא מעתיק תוכן.** נבנה רק קטלוג: שמות, מחברים ומיקום בעץ, מהתוכנה שמותקנת אצל המשתמש.
- **הספר נפתח רק בבר אילן**, לא בתוך אוצריא.
- **שום מידע לא יוצא מהמחשב.**

## דרישות

- Windows;
- בר אילן מותקן, בכל מהדורה;
- אוצריא עם תמיכה בתוספים.

## מבנה

| תיקייה | תוכן |
|---|---|
| `helper/` | השירות המקומי (Dart). המנוע נלקח מ-[Otzaria/otzaria#1572](https://github.com/Otzaria/otzaria/pull/1572) |
| `plugin/` | התוסף |
| `installer/` | מתקין אחד לשירות ולתוסף |
| `docs/` | פרוטוקול ותיעוד |

## פיתוח

```bash
cd helper
dart pub get
dart analyze
dart test
dart build cli        # → build/cli/windows_x64/bundle/
```

בדיקות `live_*` הן כלי מדידה מול בר אילן חי, ורצות רק עם `--run-skipped`.
